# Financial Fraud Detection and Risk Assessment in Mobile Transactions Using Logistic Regression

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Train the model (downloads dataset automatically from Kaggle on first run):
   ```bash
   python train_model.py
   ```

3. Launch the app:
   ```bash
   streamlit run app.py
   ```

## Notes

- The dataset (~471MB) is not included in this repository. It is downloaded automatically via `kagglehub` when you run `train_model.py`.
- Requires a Kaggle account and `~/.kaggle/kaggle.json` API credentials.
- `model.pkl` and `metadata.json` are generated by `train_model.py` and are also not tracked by git.
